# std/fixedarray

Helpers over `FixedArray`, an array whose length is part of its type.

```narra fragment
import * as FixedArrays from "std/fixedarray"
```

The guide teaches it in [chapter 17, Proofs and compile-time constants](../../guide/17-proofs-and-compile-time.md).

## Functions

### get

```narra fragment
export function get<T, N>(values: FixedArray<T, N>, index: int): Option<T> from values
```

Returns the value at index, or `None` when index is outside 0 to `N - 1`.

Effects: none.

### length

```narra fragment
export function length<T, N>(_values: FixedArray<T, N>): int
```

Returns `N`, the length that is part of the array's type.

Effects: none.
