A socket that accepts connections on host and port. host is a numeric IPv4 or IPv6 address, with no name lookup. Port 0 picks a free port, which localPort gives.

### connect

A connection to host and port, once the peer accepts it. host is a numeric IPv4 or IPv6 address, with no name lookup.

Effects: `io`, `alloc`.

### read

```narra fragment
export async function read(connection: Connection, maxBytes: int): Result<bytes, AsyncError> uses io, alloc
```

Up to maxBytes bytes from the connection, at most 64 KiB, once some are there. Empty bytes mean the peer has closed its side; a maxBytes of zero or less gives empty bytes at once.

Effects: `io`, `alloc`.

### chunks

```narra fragment
export async function* chunks(connection: Connection, maxBytes: int): AsyncGenerator<Result<bytes, AsyncError>> uses (io, alloc)
```

The reads of the connection as a stream: Ok(chunk) for each read of up to maxBytes bytes, until the peer closes its side. An error gives one Err, and then the stream ends, so a reader can tell the end from a failure. A maxBytes of zero or less ends the stream at once, as read gives empty bytes.

Effects: `io`, `alloc`.

### write

```narra fragment
export async function write(connection: Connection, data: bytes): Result<int, AsyncError> uses io, alloc
```

Writes every byte of data and gives the count. A cancel while it waits ends it with Err(AsyncError.Cancelled), whatever part was sent.

Effects: `io`, `alloc`.
