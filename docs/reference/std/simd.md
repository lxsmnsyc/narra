## Functions

Details for every function below: V: a vector type such as I32x4 (listed above), M: the signed integer vector of the same shape (its mask), L: the lane type of V, N: its lane count.

### abs

```narra fragment
export function abs<V>(vector: V): V
```

Gives the absolute value of each lane. On integer lanes the most negative value stays negative, because the negation wraps.

Effects: none.

### all

```narra fragment
export function all<M>(mask: M): bool
```

Tells whether every lane of the mask is not zero.

Effects: none.

### any

```narra fragment
export function any<M>(mask: M): bool
```

Tells whether at least one lane of the mask is not zero.

Effects: none.

### equal

```narra fragment
export function equal<V, M>(first: V, second: V): M
```

Gives a mask with `-1` in each lane where they are equal and `0` elsewhere. A NaN lane is never equal.

Effects: none.

### fromFixed

```narra fragment
export function fromFixed<L, const N: int, V>(values: FixedArray<L, N>): V
```

Makes a vector from a `FixedArray` with the same lane type and lane count, lane 0 first.

Effects: none.

### max

```narra fragment
export function max<V>(first: V, second: V): V
```

Gives the larger lane of the two vectors in each position. Where either lane is NaN, the result takes the lane of `second`.

Effects: none.

### min

```narra fragment
export function min<V>(first: V, second: V): V
```

Gives the smaller lane of the two vectors in each position. Where either lane is NaN, the result takes the lane of `second`.

Effects: none.

### notEqual

```narra fragment
export function notEqual<V, M>(first: V, second: V): M
```

Gives a mask with `-1` in each lane where they differ and `0` elsewhere. A NaN lane always differs.

Effects: none.

### select

```narra fragment
export function select<M, V>(mask: M, ifTrue: V, ifFalse: V): V
```

Takes the bits of `ifTrue` where the mask bits are set and the bits of `ifFalse` elsewhere. A mask from a comparison picks whole lanes.

Effects: none.

### shiftLeft

```narra fragment
export function shiftLeft<V>(vector: V, count: int): V
```

Shifts every lane left by `count` bits. The bits shifted out of the lane are lost.

Effects: none.

Details: count: a constant from 0 to the lane bits - 1, or a name checked against both ends.

### shiftRight

```narra fragment
export function shiftRight<V>(vector: V, count: int): V
```

Shifts every lane right by `count` bits. Signed lanes copy their sign bit and unsigned lanes fill with zeros.

Effects: none.

Details: count: a constant from 0 to the lane bits - 1, or a name checked against both ends.

Effects: none.

Details: lanes: a list literal of constants, one per lane.

### splat

### store

```narra fragment

```

Writes the lanes into `items` from index `start` and gives `true`. When the lanes do not all fit, it writes nothing and gives `false`.

Effects: none.

### sum

```narra fragment
export function sum<V, L>(vector: V): L
```

Adds all the lanes. Integer lanes wrap, and float lanes are added in pairs, so rounding can differ from a left to right sum.

Effects: none.
