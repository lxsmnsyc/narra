### pointer

Returns a pointer to the zero-terminated text, for a C function that takes `char*`. The pointer is valid only while the `CString` is.

Effects: none.

### read

```narra fragment
export function read(address: Ptr<u8>): Result<string, string> uses alloc, unsafe
```

Copies the zero-terminated string at `address` into a new string, or gives an error when it is not valid UTF-8. `address` must point to a zero-terminated string.

Effects: `alloc`, `unsafe`.
