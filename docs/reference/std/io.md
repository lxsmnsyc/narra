## Functions

### flush

```narra fragment
export function flush() uses io
```

Sends the text that `write` has buffered to standard output now.

Effects: `io`.

### readAll

```narra fragment
export function readAll(): Result<string, string> uses io, alloc
```

Reads the rest of standard input as text. Input that is not valid UTF-8 is an `Err`.

Effects: `io`, `alloc`.

### readBytes

```narra fragment
export function readBytes(count: int): Result<string, string> uses io, alloc
```

Reads exactly `count` bytes of standard input as text. Fewer bytes before the input ends, a negative count or text that is not valid UTF-8 is an `Err`.

Effects: `io`, `alloc`.

### readLine

```narra fragment
export function readLine(): Result<Option<string>, string> uses io, alloc
```

Reads the next line of standard input without its `\n`, and gives `Ok(None)` at the end of the input. A `\r` before the `\n` stays in the line.

Effects: `io`, `alloc`.

### write

```narra fragment
export function write(text: string) uses io
```

Writes text to standard output, without a line end. The text can wait in a buffer until `flush` or the end of the program.

Effects: `io`.

### writeError

```narra fragment
export function writeError(text: string) uses io
```

Writes text to standard error, without a line end.

Effects: `io`.
