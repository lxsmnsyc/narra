- 2026-11-12: branch feat/generic-implement reset to feat/batch-11. Scratch /private/tmp/claude-501/generic-implement. Base compiler from `sh selfhost/bootstrap.sh`; dev compiler built by emitting selfhost with it and `cc -O1`.
- Step 1 (constraints). Parser: `parseTypeParamsNoBounds` became `parseTypeDeclParams(allowConstants, allowBounds)`; `parseTypeParams` takes `allowBounds`. Aliases pass false, so `type P<T: Show>` is the ordinary E0011 `expected ">", found ":"`. AST `bounds` on StructDecl and EnumDecl (default `[]`), printed by astdump (`bound` slots, shared `dumpBounds`), fmt and querysignature (`writeBoundedParameters`).
- Bounds go into `Checker.bounds` in `declareModuleBounds` (typebounds.nra), right after declareTraits. The use-site check cannot run in resolveType directly: resolve.nra cannot import traits.nra (traits imports resolve). So each use queues a `TypeBoundCheck` (`noteTypeBounds` in check.nra, like `checkMapKey`) and `flushTypeBounds` runs beside flushMapKeys, in declarePackage and checkModules. Deferring also means user structs have their fields when `typeImplements` runs.
- Step 2 (generic implement). resolveImpl: the head is checked by `checkImplementHead` (genericimpl.nra, E1021), the open type `Pair<T>` is resolved with the type's parameters in the environment, members are checked against the trait with Self = the open type. Each member is also registered as a generic `FuncInfo` named `__implement_<Type>_<Trait>_<member>` with `selfType: Some(open type)`; the leading `_` keeps it out of E0947. Not in scope maps, not in programFunctions. The block stays in `checker.implementations` (forType = open type) so body.nra, query.nra, declsdump.nra and effects.nra readers work unchanged.
- body.nra checkImplBodies: a generic member body is checked with makeEnv(parameters) + Self, no body key, funcIndex = the member.
- instances.nra addFuncInstance: a member instance also gets `Self` in its environment (substituted open type), so `const x: Self` works in member bodies.
- implementations.nra: `findImplementation` (creates the member instance), `lookupImplementation` (emitter, no creation), `setImplementationRef`, `addImplementInstances`. checkPending calls addImplementInstances first and whenever the queue drains: every concrete instance of a generic type with blocks gets all member instances, so the emitter's writeDefinition finds them for `==`, map keys, derived Ordered and Show of enclosing types. Instances whose arguments fail the type's bounds are skipped (no cascades).
- Import cycles shaped the split: genericimpl.nra (imported by traits.nra) imports no traits; implementations.nra imports traits, typebounds and instances.
