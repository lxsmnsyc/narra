## Types

### Sender

```narra fragment
export opaque struct Sender<T>
```

The sending end of a channel. Copies share it, and the channel closes when the last copy is dropped.

Functions: [`create`](#create), [`send`](#send), [`close`](#close).

### Receiver

```narra fragment
export opaque struct Receiver<T>
```

The receiving end of a channel. Copies share it, and once the last copy is dropped, send gives false.

Functions: [`create`](#create), [`receive`](#receive), [`values`](#values).

## Functions

### create

```narra fragment
export function create<T>(capacity: int): #[Sender<T>, Receiver<T>] uses alloc
```

A channel with room for capacity values; a capacity below 1 is 1. The element type must be Sendable, or the call does not compile.

Effects: `alloc`.

### send

```narra fragment
export function send<T>(sender: Sender<T>, value: T): bool uses io
```

Queues value, waiting while the channel is full. Gives false, and keeps nothing, once the channel is closed or every receiver is gone.

Effects: `io`.

### receive

```narra fragment
export function receive<T>(receiver: Receiver<T>): Option<T> uses io
```

Takes the oldest value, waiting while the channel is empty. Gives None once the channel is closed and empty.

Effects: `io`.

### values

```narra fragment
export function* values<T>(receiver: Receiver<T>): Generator<T> uses io
```

The values of the channel, in the order they were sent, until it is closed and empty.

Effects: `io`.

### close

```narra fragment
export function close<T>(sender: Sender<T>)
```

Closes the channel for every copy of the sender. The values already queued can still be received.

Effects: none.
