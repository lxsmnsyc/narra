## Constants

### PI

```narra fragment
export const PI: f64
```

The ratio of a circle's circumference to its diameter, to `f64` precision.

## Functions

### from

```narra fragment
export function from<T>(value: T): f64
```

Converts an `f32` or an integer to `f64`. An `f32` converts exactly, and an integer beyond 2 to the power 53 rounds to the nearest `f64`.

Effects: none.

### fromInt

```narra fragment
export function fromInt(value: int): f64
```

Converts an `int` to `f64`. An integer beyond 2 to the power 53 rounds to the nearest `f64`.

Effects: none.

### sqrt

```narra fragment
export function sqrt(value: f64): f64
```

Gives the square root. A negative value gives NaN.

Effects: none.

### toFixed

```narra fragment
export function toFixed(value: f64, digits: int): Option<string> uses alloc
```

Writes the value with `digits` digits after the point, rounded. Gives `None` when `digits` is below 0 or above 20.

Effects: `alloc`.

### toString

```narra fragment
export function toString(value: f64): string uses alloc
```

Writes the shortest text that reads back as the same value, with at least one digit after the point. NaN and the infinities are `nan`, `inf` and `-inf`.

Effects: `alloc`.

### truncate

```narra fragment
export function truncate(value: f64): Option<int>
```

Drops the fraction and gives the `int`. Gives `None` for NaN, the infinities and any value outside the `int` range.

Effects: none.

### parse

```narra fragment
export function parse(text: string): Result<f64, string> uses alloc
```

Reads decimal text as an `f64`: an optional sign, digits with an optional point, and an optional exponent. `nan`, `inf`, spaces and a number too large for `f64` are errors.

Effects: `alloc`.
