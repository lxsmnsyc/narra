# Log: pkg-yaml

- Checked for existing work: no `packages/yaml`, no yaml module in `std/`, no YAML code elsewhere in the repo. Started from `feat/batch-26`.
- Vendored the yaml-test-suite from the `data-2022-01-17` tag of https://github.com/yaml/yaml-test-suite (it resolves to commit `6e6c296ae9c9d2d5c4134b4b64d01b29ac19ff6f`), MIT license copied to `packages/yaml/suite/LICENSE`. Kept `===` (name), `in.yaml`, `in.json` and `error` of each case: 402 cases, 18 KB of text. The suite's `out.yaml`, `emit.yaml` and `test.event` files are left out, since the checks compare values, not events.
- Design: one module `yaml` (reader and public API in `src/yaml.nra`), private `scalar` (core schema rules, shared with the writer) and `writer`. A module cannot re-export, so the public types live in `yaml.nra` and the writer and scalar modules do not use them. Inside the package the module is `yaml/yaml`; outside it is `yaml`.
- The reader is a recursive descent over bytes with a table of line starts, so columns cost a binary search and no scan. It loops over sequences, lines and tokens and recurses only on the nesting of collections.
- First run of the suite: 356 of 402 passed. Fixes in order: properties on several lines (`&a` and `!!map` on lines of their own, then `&k key:` on the key line), an anchor or tag on an empty key (`!!null : a`), plain scalars that continue over lines in a flow collection up to a colon, a `%YAML 1.1#...` version with a stuck comment, a tab where a block scalar line needs spaces, and a tab between `-` and a nested block collection. Then 369 passed and 33 left out (see the outcome).
- Stack use: under `-sanitize` the frames are large, and 512 levels of block mapping overflowed the 8 MB stack at about 400 levels. `parseBlockNode` was split into `readNodeHead` (everything that does not recurse) and a small dispatcher, `readEntryValue` was inlined, and the flow collection path dropped one frame per level. After that 512 levels of flow, block sequence, block mapping and alternating sequence and mapping all pass under `-sanitize`, and 700 levels of block mapping still fit. Without the sanitizer about 1000 levels fit.
- A found bug in the writer while running the round trip: the check for ` #` and `: ` inside a string tested the wrong bytes. The round trip over 3000 random values and the fuzz over 6000 texts found it at once; after the fix they pass.
- `Float.parse` does not take `inf` or `nan`, so the reader builds infinity as `1.0e308 * 10.0` and NaN as `inf - inf`. Floats are not rounded in the round trip: `Float.toString` gives digits that parse back to the same value.
- Style pass: removed the `//` comments above private functions (the maintainer's rule), moved the ones that mattered into the function bodies, renamed `columnOf`, `noProps` and `emptyToken` to action names, formatted with `narrac fmt`.
