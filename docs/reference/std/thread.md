### Scope

The scope that `scope` gives its body, for starting threads. Every thread started in it has ended when `scope` returns.

## Functions

### scope

```narra fragment
export function scope<T, effect E>(body: (Scope) => T uses E): T uses E, alloc
```

Calls body with a new scope and gives its result once every thread started in the scope has ended.

Effects: `E`, `alloc`.

### start

```narra fragment
export function start<T, effect E>(threadScope: Scope, escaping work: () => T uses E): Thread<T> uses E, alloc
```

Runs work on a new thread of the scope, with an 8 MiB stack. A work that returns nothing gives a Thread\<void\>, whose join returns nothing. A panic on the thread ends the whole program.

Effects: `E`, `alloc`.

### startAsync

```narra fragment
export function startAsync<T, effect E>(threadScope: Scope, escaping work: () => Async<T> uses E): Thread<T> uses E, alloc
```

Runs work, an async function, on a new thread of the scope. The thread's own event loop runs its task, and join gives the value the task returns. Once the task has finished, the thread cancels and drains the tasks still running.

Effects: `E`, `alloc`.

### join

```narra fragment
export function join<T>(thread: Thread<T>): T from thread
```

Waits until the thread has ended and gives its result. A second join gives the same value without waiting.

Effects: none.
