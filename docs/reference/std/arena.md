# std/arena

Values in slots, reached through handles that check the generation of the slot.

## Types

### Handle

```narra fragment
export opaque struct Handle<T> derives Equatable, Hashable, Show
```

A reference to one value of an `Arena<T>` that finds nothing once the value is removed. A handle used with another arena is not caught, and reads the same slot there.

Functions: [`insert`](#insert), [`contains`](#contains), [`get`](#get), [`set`](#set), [`update`](#update), [`remove`](#remove), [`entries`](#entries).

### Arena

```narra fragment
export opaque struct Arena<T>
```

Values of type `T` in numbered slots, each reached through the `Handle<T>` that `insert` gave.

Functions: [`create`](#create), [`insert`](#insert), [`contains`](#contains), [`size`](#size), [`get`](#get), [`set`](#set), [`update`](#update), [`remove`](#remove), [`clear`](#clear), [`entries`](#entries).

### remove

```narra fragment

```

Takes the value of the handle out of the arena, or returns `None` when the handle finds none. The handle and every copy of it then find nothing.

Effects: `alloc`.

### clear

```narra fragment

```

### entries
