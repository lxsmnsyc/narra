## Functions

### parse

```narra fragment
export function parse(text: string): Option<Version> uses alloc
```

Parses MAJOR.MINOR.PATCH with an optional `-prerelease` and `+build`. Returns `None` for anything else, such as `1.2`, `01.2.3` or `1.2.3-`.

Effects: `alloc`.

### toString

```narra fragment
export function toString(version: Version): string uses alloc
```

Returns the version as text, such as `1.2.3-rc.1+build.5`.

Effects: `alloc`.

### compare

```narra fragment
export function compare(left: Version, right: Version): int
```

Compares two versions by precedence and returns -1, 0 or 1. Build metadata is ignored, so `1.0.0+a` and `1.0.0+b` give 0.

Effects: none.

### bump

```narra fragment
export function bump(version: Version, part: Part): Version uses alloc
```

Returns the version with one part raised by one. The parts below it become 0, and the prerelease and build metadata are dropped.

Effects: `alloc`.

### satisfies

```narra fragment
export function satisfies(version: Version, requirement: string): bool uses alloc
```

Tells whether the version is at least the requirement, written MAJOR.MINOR.PATCH as in a `narra.toml` dependency. A requirement of any other form gives `false`.

Effects: `alloc`.
