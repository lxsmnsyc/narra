# std/digest

SHA-256, SHA-1, HMAC and PBKDF2-HMAC-SHA-256 over bytes.

```narra fragment

```

## Types

### Algorithm

```narra fragment
export enum Algorithm derives Show, Equatable {

  Sha1

```

The hash functions this module computes.

Functions: [`create`](#create), [`hmac`](#hmac).

### Hasher

```narra fragment
export opaque struct Hasher
```

A hash in progress. Make one with `create`, feed it with `update` and read the digest with `finish`. Its fields are internal. Copy it with `copy(hasher)` to continue two inputs from a shared prefix.

Functions: [`create`](#create), [`update`](#update), [`finish`](#finish).

## Functions

### create

```narra fragment
export function create(algorithm: Algorithm): Hasher uses alloc
```

Starts a hash of the given algorithm over empty input.

Effects: `alloc`.

### update

```narra fragment
export function update(mutable hasher: Hasher, data: bytes) uses alloc
```

Adds bytes to the hash. Calling it with the parts of a message in order gives the same digest as one call with the whole message, whatever the sizes of the parts.

Effects: `alloc`.

### finish

```narra fragment
export function finish(hasher: Hasher): bytes uses alloc
```

Gives the digest of everything fed so far: 32 bytes for SHA-256, 20 for SHA-1. The hasher is not changed, so it can take more input afterwards.

Effects: `alloc`.

### sha256

```narra fragment
export function sha256(data: bytes): bytes uses alloc
```

Gives the SHA-256 digest (32 bytes) of the data.

Effects: `alloc`.

### sha1

```narra fragment
export function sha1(data: bytes): bytes uses alloc
```

Gives the SHA-1 digest (20 bytes) of the data. SHA-1 is broken for signatures; use it only where a protocol demands it, such as the WebSocket handshake.

Effects: `alloc`.

### hmac

```narra fragment
export function hmac(algorithm: Algorithm, key: bytes, message: bytes): bytes uses alloc
```

Gives the HMAC (RFC 2104) of the message under the key, with the given hash.

Effects: `alloc`.

### pbkdf2Sha256

```narra fragment
export function pbkdf2Sha256(password: bytes, salt: bytes, iterations: int, length: int): Option<bytes> uses alloc
```

Derives `length` bytes from a password with PBKDF2-HMAC-SHA-256 (RFC 8018). Gives `None` when `iterations` is below 1, `length` is negative, or `length` is above 32 times 2^32 - 1.

Effects: `alloc`.

### equal

```narra fragment
export function equal(first: bytes, second: bytes): bool
```

Tells whether two digests are equal. For equal lengths the loop has no early exit, so it is meant to take the same time wherever the digests differ; the language does not promise constant time in the generated C. Digests of different lengths are not equal.

Effects: none.
