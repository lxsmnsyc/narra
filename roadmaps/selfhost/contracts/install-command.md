# install-command

The install commands the site and docs show.

macOS and Linux:

    curl -fsSL https://github.com/lxsmnsyc/narra/releases/latest/download/install.sh | sh

Windows (PowerShell):

    irm https://github.com/lxsmnsyc/narra/releases/latest/download/install.ps1 | iex

Both install `narrac` and print the next step. A change to either line is a change request.
