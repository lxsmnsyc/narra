# compiler/internal/narra

- Add a std function only as an entry in its module's `std_*.go` file (`registerModule`). Do not add cases to `check_call.go` or `emit_call.go`. A new module is a new `std_<name>.go`.
- Put a module's runtime C in `Module.Runtime`, not in `runtime.h`.
- Report compile errors through `c.errorf` or `c.report`, which build a `Diagnostic`. Do not build error strings by hand.
- Every `Builtin.Name` must be unique. Registration panics on a duplicate.
- Registration runs in `init()`, and Go runs `init` in file name order. Do not depend on the order between modules.
- A refactor must keep the generated C and the error text byte-identical. Compare the output for every file in `compiler/testdata/` before and after.
- Build C names only through `CName()` and `funcCName`, never from `Name`. Names carry the module.
- Compare struct and enum types by module and name, never by name alone.
- Before resolving another module's types or checking its bodies, `enter` that module's scope, as `funcInstance` and `buildGeneric` do.
- Cross-module tests go in `compiler/testdata/packages/<name>/` (with `run.out`) or `compiler/testdata/packages/errors/<name>/` (first line of `narra.toml` is `# error: <text>`).
- Emit calls to the standard trait functions through `e.useEq`, `e.useHash`, `e.useCmp` and `e.useShow`, not `eqFunc(t)` or a hand-built `eq_<type>`. The definition is only emitted when requested.
- All C names are made in `cnames.go`. Names may contain `_` anywhere. A new kind of generated name goes there too.
- Create function types only through `c.funcOf`. The emitter writes C structs only for function types it has listed.
- New per-function emitter state must be saved and restored in `closureFunc`, because closures are emitted in the middle of another body.
- Emit pattern tests as `&&` chains, with each tag test before any read of its union member.
- Names bound by a pattern retain when bound and release when the scope pops. Never borrow from the match subject.
- Give each heap or interned kind its own kind letter in `cnames.go` (`B` box, `Q` enum payload), and register it. A shared letter can clash with declaration names.
- Put the operation before the type in generated helper names (`retain_S_...`). A suffix such as `<type>_retain` can equal a user type name.
- An enum with a fielded variant holds `{ tag; Q* u }`. Build such a value only with `e.enumAlloc`, and read fields as `v.u->variant.field`. Never write `.u.` or a `{.tag=..., .u...}` literal by hand, because the payload is a shared heap pointer that is never mutated.
- Free heap values through the `narra_drop` worklist (`runtime.h`), never by recursive release. A 1,000,000-long list must drop without growing the C stack.
- Check a generic type for a growing self-reference at declaration time (`checkPolyRecursion`). Instantiation loops forever otherwise. `List<T>` holding `Array<List<T>>` is allowed.
- A std builtin that returns `Result` fills out-parameters in its runtime C and builds the value with `ioResult`/`ioEither` (`std_fs.go`). Runtime C cannot name per-program types, since `Module.Runtime` is emitted before them.
- Error tests that list std modules (`unknown_module.nra`) match a prefix only. The list grows with every std node.
- Every error format needs a code in `diagnosticCodes` (`diagnostic_codes.go`), because the code is looked up from the format string. Pass the format as a string literal at the call site, or it gets `E0000`. `TestEveryFormatHasCode` fails on a missing entry.
- To add a code: take the next free number in the range for the area (the table comments list the ranges), append `{"E0NNN", "<exact format>"}`, and add a `testdata/errors/` test. Never renumber or reuse a code. Rewording a format means rewording its table entry too, keeping the code.
- A TypeScript-habit error should carry an exact fix (`c.errorfFix`, `p.failFix`) and a `testdata/diagnostics/` case whose first line is `// code: E0NNN`. The test applies the fix and the file must compile.
- Register a std type name (such as `StringBuilder`) only in modules that import the std module whose `Module.Runtime` defines it. Otherwise the C names a type whose runtime is not emitted.
- Set `Builtin.Effects` on every std builtin. The effect pass reads it, and a missing entry makes the builtin pure.
- A builtin with a `Mutable` parameter: check the argument expression before `checkMutableArg`, or the root local is unresolved.
- Emit a statement call that returns a value through `e.temp`. `ExprStmt` prints only void calls, so the call is dropped otherwise.
- Map key checks are queued (`checkMapKey`) and run after all modules are checked (`flushMapKeys`), so trait facts of later types are known. Check key types in signatures too, not only in bodies.
- Before a `switch t.(type)` over base kinds, call `underlying(t)` or add a `*DistinctType` case. A distinct type shares its base's C type but has its own `typeID`.
- Read a top-level constant only through `e.constRef`. Non-scalar constants are built on first use by a getter that returns a borrowed value, and freed in `narra_consts_release`.
- Name resolution is local, then constant, then function, and a constant may not share a name with a function or a type.
- `clone.go` must copy every field of an AST node, including positions such as `StringLit.End`. Fixes and diagnostics in generic instances read them.
- Never name a compiler source file `*_test.go`: Go builds it only under `go test`, so its code is missing from the `narra` binary. `std/test` lives in `std_testing.go`.
