# Outcome: seed-file

## Built

- `seed/narrac.c` (6.2 MB, about 140000 lines, 2.8 MB binary): the C that the self-hosted compiler emits for `selfhost/`. A 9-line comment header ends with a line ` */`; everything after it is the compiler's own `emit` output. First version made from Go's `narra emit selfhost` (the same C as stage 2), then rewritten by `seed-update.sh`. Header names the last commit that changed `selfhost/` (`de4096e`).
- `selfhost/bootstrap.sh [outdir]`, run as `sh selfhost/bootstrap.sh`. No `go`.
  - Stage 0: `$CC` (else `cc`) `-O2 -DNARRA_RELEASE -std=c11 -w -o narrac0 seed/narrac.c -lm`.
  - Stage 1: `narrac0 emit selfhost > stage1.c`, then the same cc call builds `narrac1`.
  - Stage 2: `narrac1 emit selfhost > stage2.c`.
  - `cmp stage1.c stage2.c`. Equal: prints `ok: ...`. Then prints `seed is current` when the seed body (text after the header) equals `stage2.c`, else a `note:` that the seed is older than the source (not a failure).
  - With `outdir`: copies `narrac1` to `outdir/narrac` and `stage2.c` to `outdir/stage2.c` (only after the fixed point holds).
  - Exit codes: 0 fixed point holds; 1 the C differs or any step fails (`set -e`; cc or emit failure ends the script with that command's non-zero status, usually 1); 2 more than one argument. Temp dir is removed on exit.
- `scripts/seed-update.sh`: no arguments (2 on bad usage). Runs `selfhost/bootstrap.sh` into a temp dir, builds the header (commit from `git log -1 --format=%h -- selfhost`, or `unknown` without git) plus `stage2.c`, and writes `seed/narrac.c` only if it differs. Prints `seed unchanged` or `seed updated: seed/narrac.c`. Exit 0 on either; non-zero (bootstrap's code, `set -e`) when the fixed point fails, with the seed untouched.
- `.gitattributes`: `seed/narrac.c linguist-generated=true -diff`.
- `seed/README.md`: the seed rule, how to build and regenerate, when to regenerate.
- `compiler/README.md` "Bootstrapping" and the status line in `README.md` updated.

## Deviations

- The header commit is the last commit that changed `selfhost/`, not HEAD, so a commit that only changes the seed does not make the next run rewrite it. It is also what the brief's "unchanged tree stays byte-identical" needs. Std and runtime text live inside `selfhost/src`, so they are covered.
- `bootstrap.sh` takes an optional `outdir` (not in the brief), so `seed-update.sh` reuses it.
- The Go-vs-seed check of the old script is gone. `TestSelfhostBootstrap` still covers Go vs stage 2.

## Stubs left

- `scripts/linux-check.sh` and `scripts/linux/Dockerfile` still run Go tests (owned by retire-go). They were not used for the Linux check here.

## Gotchas

- The seed is only current while `selfhost/` is unchanged. Any node that edits `selfhost/src` (checker-codes, test-runner-core's driver changes) makes the bootstrap print the `note:`; run `sh scripts/seed-update.sh` after the story's last source change, and commit the seed in the same commit, or its header commit will be stale. The header hash is of a commit that exists before the seed commit, so the final regenerated seed should be made after the source commits.
- A merge that changes `selfhost/` on two branches leaves the seed to be regenerated by the orchestrator (the file is `-diff` and will conflict as a whole file: regenerate, do not merge).
- `seed-update.sh` needs git for the header; in a copied tree without git history the header says `unknown`, so do not run it there for a commit.
- Docker on colima mounts only the home folder: a script under `/private/tmp` mounts as an empty file.
- The seed compiles in about 1 minute with `-O2` on macOS.

## Proposed learnings

- Never edit `seed/narrac.c` by hand; regenerate it with `scripts/seed-update.sh` | it is generated and a merge conflict cannot be resolved by reading it | seed/ | no
