# std/json

Parse and write JSON text as a `Value` of `std/shape`, or as any `Shape` type.

```narra fragment
import * as Json from "std/json"
```

The guide teaches it in [chapter 7, Traits](../../guide/07-traits.md).

This page is generated by `scripts/std/generate.nra` from `narrac query --json interface std/json`. Do not edit it.

## Functions

### parse

```narra fragment
export function parse(text: string): Result<Value, string> uses alloc
```

parse reads one JSON value. Errors read `<line>:<column>: <reason>`, and containers nested deeper than 512 levels are an error.

Effects: `alloc`.

### stringify

```narra fragment
export function stringify(value: Value): string uses alloc
```

stringify writes a value as compact JSON text. A non-finite Float is null.

Effects: `alloc`.

### encode

```narra fragment
export function encode<T: Shape>(value: T): string uses alloc
```

encode writes any value that implements Shape as compact JSON text.

Effects: `alloc`.

### decode

```narra fragment
export function decode<T: Shape>(text: string): Result<T, string> uses alloc
```

decode reads JSON text as a T: `Json.decode<User>(text)`. A parse error is passed through; a shape error reads `<path>: <reason>` (see std/shape).

Effects: `alloc`.
