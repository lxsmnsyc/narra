## Functions

### basename

```narra fragment
export function basename(path: string): string uses alloc
```

Gives the last part of the path, ignoring trailing separators. The root `/` gives `""`.

Effects: `alloc`.

### dirname

```narra fragment
export function dirname(path: string): string uses alloc
```

Gives the path without its last part, or `.` when it has only one part.

Effects: `alloc`.

### extname

```narra fragment
export function extname(path: string): string uses alloc
```

Gives the last part's extension from its last dot, such as `.txt`, or `""` when it has none. A name whose only dot is its first character, such as `.profile`, has none.

Effects: `alloc`.

### join

```narra fragment
export function join(first: string, second: string): string uses alloc
```

Joins two paths with `/` and normalizes the result, removing `.` parts and resolving `..`. An absolute `second` is still added after `first`, not used alone.

Effects: `alloc`.
