# std/range

Ranges of integers for `for ... of` loops.

```narra fragment
import * as Ranges from "std/range"
```

## Functions

### between

```narra fragment
export function between(start: int, end: int): Range
```

Counts from start up to but not including end, and is empty when end is not above start.

Effects: none.

### stepped

```narra fragment
export function stepped(start: int, end: int, step: int): Range
```

Counts from start by step, up to but not including end, and counts down when step is negative. A step of 0 known only at run time gives an empty range.

Effects: none.

### upTo

```narra fragment
export function upTo(count: int): Range
```

Counts from 0 up to but not including count.

Effects: none.
