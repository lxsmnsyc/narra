## Functions

### wait

```narra fragment
export async function wait(): Result<Signal, AsyncError> uses io, alloc
```

The next SIGINT or SIGTERM, waiting until one comes. The first call catches both signals for the rest of the program. A cancel ends the wait with Err(AsyncError.Cancelled). A second wait on the same loop while one is pending gives Err(AsyncError.Failed(...)).

Effects: `io`, `alloc`.
