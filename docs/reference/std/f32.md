## Functions

### from

```narra fragment
export function from<T>(value: T): f32
```

Converts an `f64` or an integer to `f32`, rounding to the nearest `f32`.

Effects: none.

### toString

```narra fragment
export function toString(value: f32): string uses alloc
```

Writes the shortest text that reads back as the same `f32`, with at least one digit after the point. NaN and the infinities are `nan`, `inf` and `-inf`.

Effects: `alloc`.

### truncate

```narra fragment
export function truncate(value: f32): Option<int>
```

Drops the fraction and gives the `int`. Gives `None` for NaN, the infinities and any value outside the `int` range.

Effects: none.
