# Standard library

Every public module of the standard library. A module page lists its types, functions and constants with their signatures and effects, and links to the guide chapter that teaches the module.

These pages are generated by `scripts/std/generate.nra` from `narrac query --json interface`. Do not edit them.

## Modules

- [`std/arena`](arena.md): Values in slots, reached through handles that check the generation of the slot.
- [`std/args`](args.md): A command line as data: flags, positionals and subcommands, parsed in one call.
- [`std/array`](array.md): Arrays: length, push, slices and loops over values and entries.
- [`std/async`](async.md): Task handles of async functions: wait for all, the first, or cancel.
- [`std/atomic`](atomic.md): `Atomic<T>`, a bool or an integer with atomic operations.
- [`std/box`](box.md): `Box<T>`, a value behind a reference, for recursive data.
- [`std/build`](build.md): The target a program is built for: operating system, architecture and build mode.
- [`std/bytes`](bytes.md): Byte strings: conversion from and to arrays and text, slices and concatenation.
- [`std/cell`](cell.md): `Cell<T>`, one mutable slot that every copy of the handle shares.
- [`std/channel`](channel.md): Bounded channels between threads.
- [`std/char`](char.md): Characters and their code points.
- [`std/coroutine`](coroutine.md): Resume a generator by hand and send values into it.
- [`std/cstring`](cstring.md): `CString`, a string with no zero byte, which C reads as a zero-terminated string.
- [`std/env`](env.md): The command line arguments and the environment variables of the process.
- [`std/f32`](f32.md): 32-bit floats: conversion, truncation and text.
- [`std/fixedarray`](fixedarray.md): Helpers over `FixedArray`, an array whose length is part of its type.
- [`std/float`](float.md): 64-bit floats: conversion, square root, truncation, text and `PI`.
- [`std/fs`](fs.md): Files and folders: read, write, list, create and remove.
- [`std/hash`](hash.md): Hashes of `Hashable` values and the FNV-1a hash of text.
- [`std/i16`](i16.md): 16-bit signed integers: checked arithmetic, conversion and text.
- [`std/i32`](i32.md): 32-bit signed integers: checked arithmetic, conversion and text.
- [`std/i8`](i8.md): 8-bit signed integers: checked arithmetic, conversion and text.
- [`std/int`](int.md): `int`, the 64-bit signed integer: checked arithmetic, division, parsing and text.
- [`std/io`](io.md): Standard input, output and error.
- [`std/iterator`](iterator.md): Lazy and eager operations over generators.
- [`std/json`](json.md): Parse and write JSON text as a `Value` of `std/shape`, or as any `Shape` type.
- [`std/map`](map.md): Maps: size, keys, entries, update and remove.
- [`std/math`](math.md): Number functions: minimum and maximum, powers, roots, rounding and trigonometry.
- [`std/net`](net.md): TCP sockets on the event loop of the thread.
- [`std/option`](option.md): Helpers over `Option`, the type of a value that may be missing.
- [`std/parallel`](parallel.md): Run a function over an array on several threads.
- [`std/path`](path.md): File paths as text: join, folder, base name and extension.
- [`std/process`](process.md): Run other programs and exit the process.
- [`std/ptr`](ptr.md): `Ptr<T>`, a raw pointer for unsafe code and C.
- [`std/random`](random.md): A seeded random number generator that gives the same numbers on every platform.
- [`std/range`](range.md): Ranges of integers for `for ... of` loops.
- [`std/regex`](regex.md): Regular expressions with a linear-time engine.
- [`std/result`](result.md): Helpers over `Result`, the type of a value or an error.
- [`std/shape`](shape.md): `Value`, a dynamic tree for structured data, and the `Shape` trait.
- [`std/shared`](shared.md): `Shared<T>`, a value guarded by a lock.
- [`std/simd`](simd.md): Vector types and operations on all their lanes at once.
- [`std/string`](string.md): Text: length, slices, search, split and join, and a builder.
- [`std/template`](template.md): The parts type and the tag of tagged templates.
- [`std/terminal`](terminal.md): Detect a terminal and style text for it.
- [`std/test`](test.md): Assertions for `test` blocks: equality, panics and golden files.
- [`std/thread`](thread.md): Threads that run in a scope.
- [`std/time`](time.md): A monotonic clock for measuring, the wall clock, and an async sleep.
- [`std/toml`](toml.md): Parse and write TOML text as a `Value` of `std/shape`.
- [`std/u16`](u16.md): 16-bit unsigned integers: checked arithmetic, conversion and text.
- [`std/u32`](u32.md): 32-bit unsigned integers: checked arithmetic, conversion and text.
- [`std/u64`](u64.md): 64-bit unsigned integers: checked arithmetic, conversion and text.
- [`std/u8`](u8.md): 8-bit unsigned integers: checked arithmetic, conversion and text.
- [`std/unicode`](unicode.md): Grapheme clusters, case mapping and display width.
