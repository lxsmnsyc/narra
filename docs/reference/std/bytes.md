## Functions

### at

```narra fragment
export function at(data: bytes, index: int): Option<u8>
```

Returns the byte at `index`, or `None` when the index is outside the data.

Effects: none.

### concat

```narra fragment

```

Returns `first` followed by `second` as one `bytes` value.

Effects: `alloc`.

### fromString


### length


### slice

```narra fragment
export function slice(data: bytes, start: int, end: int): Option<bytes> uses alloc
```

Returns the bytes from `start` up to but not including `end`, or `None` when the range is outside the data or `start` is after `end`.

Effects: `alloc`.

### toArray

```narra fragment

```

Effects: `alloc`.

### toString

```narra fragment

```

Returns the bytes as a string, or an error that names the offset of the first byte that is not valid UTF-8.

Effects: `alloc`.
