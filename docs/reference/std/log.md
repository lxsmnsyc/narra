### render

```narra fragment
export function render(logger: Logger, level: Level, message: string, fields: Array<#[string, Value]>): string uses alloc
```

Returns the line the logger writes for `level`, `message` and `fields`, without the line end. `render` does not apply the level filter; `write` does. The logger's own fields come first. A later field with the same key as an earlier one, or as `level` or `msg`, replaces its value and the key keeps its first position. In `Json` each value is escaped as `std/json` escapes it. In `Text` a key that is not a bare word is quoted like a value.

Effects: `alloc`.
