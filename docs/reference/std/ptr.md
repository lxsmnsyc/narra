## Types

### Ptr

```narra fragment
export opaque struct Ptr<T>
```

The address of a `T`, with no reference count. `T` must hold no counted value, such as a string or an array.

Functions: [`alloc`](#alloc), [`cast`](#cast), [`element`](#element), [`free`](#free), [`isNull`](#isnull), [`null`](#null), [`offset`](#offset), [`read`](#read), [`write`](#write).

## Functions

### alloc

```narra fragment
export function alloc<T>(count: int): Ptr<T> uses alloc, unsafe
```

Allocates zeroed memory for `count` values of `T` and gives a pointer to the first. It stays allocated until `Ptr.free`.

Effects: `alloc`, `unsafe`.

### cast

```narra fragment
export function cast<T, U>(pointer: Ptr<T>): Ptr<U> uses unsafe
```

Gives the same address as a pointer to `U`. Nothing checks that the memory holds a `U`.

Effects: `unsafe`.

### element

```narra fragment
export function element<T, const N: int>(pointer: Ptr<FixedArray<T, N>>, index: int): Ptr<T> uses unsafe
```

Gives a pointer to element `index` of the `FixedArray` the pointer points at.

Effects: `unsafe`.

Details: index: a constant or a name proven to be 0 to N - 1.

### free

```narra fragment
export function free<T>(pointer: Ptr<T>) uses unsafe
```

Frees memory that `Ptr.alloc` gave. A null pointer does nothing, and any later use of the pointer is undefined.

Effects: `unsafe`.

### isNull

```narra fragment
export function isNull<T>(pointer: Ptr<T>): bool
```

Tells whether the pointer is null. It reads no memory, so it needs no `unsafe` block.

Effects: none.

### null

```narra fragment
export function null<T>(): Ptr<T>
```

Gives a null pointer. It reads no memory, so it needs no `unsafe` block.

Effects: none.

### offset

```narra fragment
export function offset<T>(pointer: Ptr<T>, count: int): Ptr<T> uses unsafe
```

Gives the pointer moved by `count` values of `T`, which may be negative. Nothing checks that the result is inside the allocation.

Effects: `unsafe`.

### read

```narra fragment
export function read<T>(pointer: Ptr<T>): T uses unsafe
```

Reads the value the pointer points at. Nothing checks that the pointer is valid or not null.

Effects: `unsafe`.

### write

```narra fragment
export function write<T>(pointer: Ptr<T>, value: T) uses unsafe
```

Writes `value` where the pointer points. Nothing checks that the pointer is valid or not null.

Effects: `unsafe`.
