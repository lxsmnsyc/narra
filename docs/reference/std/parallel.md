## Functions

### map

```narra fragment
export function map<T, U, effect E>(items: Array<T>, escaping change: (T) => U uses E): Array<U> uses E, alloc
```

Gives change(item) for every item, in the order of the items. As for Thread.start, the items, the result and the captures of change must be Sendable, and change must be an arrow function written at the call or the name of a top-level function.

Effects: `E`, `alloc`.
