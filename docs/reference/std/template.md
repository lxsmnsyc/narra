## Types

### Raw

```narra fragment
export distinct type Raw = Array<string>
```

The parts of a tagged template as written in the source, with no escape decoded. A tag whose first parameter is `Raw` receives them.

Functions: [`raw`](#raw-1).

## Functions

### raw

```narra fragment
export function raw(parts: Raw, values: Array<string>): string uses alloc
```

Returns the parts as written, with each value placed between them, so an escape such as `\n` stays as two characters.

Effects: `alloc`.
