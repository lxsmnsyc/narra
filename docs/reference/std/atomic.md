## Types

### Atomic

```narra fragment
export opaque struct Atomic<T>
```

A `bool` or an integer that threads read and change with atomic operations. Copies of an `Atomic` share one value.

Functions: [`create`](#create), [`load`](#load), [`store`](#store), [`exchange`](#exchange), [`add`](#add), [`compareExchange`](#compareexchange).

### compareExchange

```narra fragment

```

Stores `replacement` only when the value equals `expected`, and tells whether it stored.
