## Types

### Url

```narra fragment
export struct Url {
  scheme: Option<string>
  userInfo: Option<string>
  host: Option<string>
  port: Option<string>
  path: string
  query: Option<string>
  fragment: Option<string>
}
```

A URI reference split into its parts. Every part is as written in the text, still percent-encoded. `host` of an IPv6 address keeps its brackets. `port` is the digits after the `:`, leading zeros included, and `Some("")` for a `:` with no digits.

Functions: [`parse`](#parse), [`toString`](#tostring), [`resolve`](#resolve).

### QueryParam

One `name=value` pair of a query string, already decoded.

## Functions

### parse

```narra fragment
export function parse(text: string): Result<Url, string> uses alloc
```

Splits a URL or a relative reference into its parts. The result is an `Err` for a space or a control character, a `%` that is not followed by two hex digits, a port that is not a number from 0 to 65535, an unclosed `[` in the host, a `:` in a host without brackets, and a relative path whose first segment has a `:`.

Effects: `alloc`.

### toString

```narra fragment
export function toString(url: Url): string uses alloc
```

Writes the URL as text: `scheme:`, then `//userinfo@host:port` when it has a host, then the path, `?query` and `#fragment`.

Effects: `alloc`.

### resolve

```narra fragment
export function resolve(base: Url, reference: Url): Result<Url, string> uses alloc
```

Resolves a reference against a base URL (RFC 3986 section 5.2, strict). The base needs a scheme, or the result is an `Err`. The dot segments of the resulting path are removed.

Effects: `alloc`.

### encode

```narra fragment
export function encode(text: string): string uses alloc
```

Percent-encodes the text for use in one part of a URL. The bytes `A-Z a-z 0-9 - . _ ~` stay; every other byte becomes `%` and two upper-case hex digits, so a space is `%20` and `/` is `%2F`.

Effects: `alloc`.

### decode

```narra fragment
export function decode(text: string): Result<string, string> uses alloc
```

Reads the percent escapes of the text and returns the text they stand for. `+` stays a `+`. The result is an `Err` for a `%` without two hex digits after it, and for bytes that are not UTF-8.

Effects: `alloc`.

### parseQuery

```narra fragment
export function parseQuery(text: string): Result<Array<QueryParam>, string> uses alloc
```

Reads an `application/x-www-form-urlencoded` query string, such as `a=1&b=x+y&a=2`, into its pairs, in order and with repeated names kept. Names and values are decoded, with `+` as a space. A pair without `=` has an empty value, and an empty piece between `&` is skipped. The text does not start with `?`. The result is an `Err` for a bad escape.

Effects: `alloc`.

### queryToString

```narra fragment
export function queryToString(params: Array<QueryParam>): string uses alloc
```

Writes the pairs as a form-encoded query string, such as `a=1&b=x+y`, in order. A space becomes `+` and every byte outside `A-Z a-z 0-9 - . _ ~` becomes a percent escape.

Effects: `alloc`.
