# spec-gap-audit log

- 2026-11-04: started. Built `narra` from origin/main (8409e3b) into a scratch dir. Each test is a small single-file program, run with `narra check|run|test` through a bundle script (`=== name mode` blocks split into files).
- Section 1-2 (bindings, functions): `Float.PI` is "a module is not a value" (std constants missing). Unused locals and parameters compile clean (README records only imports and private functions). `Int.divmod`, `Arrays.map` missing. Local `function` declarations fail to parse. Self tail calls are plain C calls: 10M iterations segfault in a debug build (exit 139), release works only because clang does TCO.
- Control flow: labels (`outer: for`) fail to parse. `Arrays.entries`, `Ranges.stepped` missing. `for ... of` accepts only the call forms `Range.upTo/between`, `Array.values`, `Map.keys/entries`: a Range in a variable, an array value and `Str.chars(s)` are rejected.
- Literals: sized types `i8..u64`, `f32` and `bytes` are "unknown type", so "a literal must fit its type" holds only for `int`. Other literal forms (hex/octal/binary, `_`, chars with `\u{}`, maps with `[key]:`, type args, tuples) work.
- Operators: all operator rows work. `Int.pow`, `Float.pow`, `Int.floorDiv` missing.
- Arrow functions: a block-body arrow passed as a call argument fails to parse when its block has two or more statements (`expected the end of the statement, found "return"`). One statement works, and so does the same arrow bound with `const`. Likely newlines are suppressed inside `( )`.
- Modules: all import/export rules work, including `export const classify = Text.classify` in a scratch package. `Arrays.push` without the import is E0308 with no fix; only `Array.push` gets E0908 with the add-import fix. `type`/`export type` aliases fail to parse (README lists it as not supported).
- Types: `b.value = v` on a `Box` emits invalid C (`member reference base type 'B_Box_* *' is not a structure`), for int, struct and string payloads. Narrowing after `if (x is None) { return }` fails on a `let` variable. `Int.compare`, `Str.find`, `Str.copy`, `Arrays.slice`, `Arrays.copy`, `Arrays.withCapacity`, `I32.from`, `F64.fromInt`, `Int.truncate` missing (spec text also mixes `F64.toString` with `Float.toString`).
- Memory: a `mutable` parameter can be returned and stored in a struct with no error. `@unique` and `--report-copies` missing. Exclusive access and copy-on-write work.
- Effects: rules work; calls through struct fields count as pure (README notes it).
- Sections 9-14: `requires`/`ensures` contracts fail to parse. `lazy` and `@const` missing (README). TypeScript habits: `class`, `interface`, `new`, `try`, `throw` give generic parse errors; `for in`, `number`, `'abc'`, `.length` have messages but no fix. `narra move`, `audit`, `query`, `fmt`, `check --all-targets` do not exist. Builds are deterministic (two emits byte-identical).
- Planned features (generators, async, threads, regions, SIMD, fixed arrays, c-interop, build conditions) checked only for "not supported" errors.
