## Types

### Shared

```narra fragment
export opaque struct Shared<T>
```

A value behind a lock, which threads can read and change. Copies are handles to one value. A call on a Shared from inside an update or read callback of the same Shared panics.

Functions: [`create`](#create), [`get`](#get), [`set`](#set), [`update`](#update), [`read`](#read).

## Functions

### create

```narra fragment
export function create<T>(value: T): Shared<T> uses alloc
```

Creates a Shared that holds value. `T` must be Sendable, or the call does not compile.

Effects: `alloc`.

### get

```narra fragment
export function get<T>(shared: Shared<T>): T from shared
```

A copy of the value: one more reference, taken with the lock held, so a set on another thread cannot free it. Like Cells.get, it shares the value the Shared holds.

Effects: none.

### set

```narra fragment
export function set<T>(shared: Shared<T>, value: T)
```

Replaces the value; the old one is dropped with the lock held.

Effects: none.

### update

```narra fragment
export function update<T, effect E>(shared: Shared<T>, change: (T) => T uses E) uses E
```

Stores change(value). The value moves out of the slot while change runs, so the Shared holds no reference to it then; a value only the Shared held is plain again, not shared.

Effects: `E`.

### read

```narra fragment
export function read<T, U, effect E>(shared: Shared<T>, look: (value: T) => U from value uses E): U from shared uses E
```

Gives look(value), with the lock held while look runs. The result may be a part of the value; it holds its own reference, taken before the lock is released.

Effects: `E`.
