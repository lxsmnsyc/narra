## Types

### StringBuilder

```narra fragment
export opaque struct StringBuilder
```

A growing buffer of text, filled with `append` and `appendChar` and read with `build`.

Functions: [`append`](#append), [`appendChar`](#appendchar), [`build`](#build), [`builder`](#builder).

## Functions

### append

