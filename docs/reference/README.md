# Reference

Pages to look things up in. To learn Narra from the start, read the [guide](../guide/README.md).

- [Std](std/README.md): every public module of the standard library, with the signature and effects of each export.
- [Commands](commands.md): every `narrac` command and flag, with exit codes and environment variables.
- [`narra.toml`](narra-toml.md): every table and key, its type and default, and the error code for a wrong value.
- [Errors](errors.md): every diagnostic code with its message and explanation.
- [Spec](../../SPEC.md): the language specification, rule by rule.
