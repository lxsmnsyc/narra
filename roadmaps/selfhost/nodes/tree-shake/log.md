- Design: emission-driven reachability. Each site that writes a C function or constant-getter name calls `noteReference` (emitstate.nra): calls (emitexprs `emitFunctionCall`), constant getters (`constRef`), function values (emitclosures thunk), and user impls named by trait functions (emittraits `writeDefinition`). `emitReachableBodies` (emit.nra) starts from the entry (or the test blocks), emits each newly named function or getter, then writes the trait functions and repeats while they name something new. No separate AST walk: a folded branch is never emitted, so it adds no edge, and every name the C uses gets emitted.
- First build: the shared-write check rejected `noteReference(mutable emitter, ...)` while a borrowed `emitter.checker` value was still in use (emitclosures thunk, emit.nra programs). Moved the thunk's note after the last use; emit.nra takes `copy(emitter.checker)`.
