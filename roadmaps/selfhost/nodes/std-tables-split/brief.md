# Split the self-hosted std tables by module

> 2026-11-09: the Go compiler and Go test harness were retired (story c-seed, PR #101). Build only in `selfhost/src` (and `std/src`, `selfhost/runtime/`); ignore the Go half of any plan below. Go test names below map to `selfhost/tests` suites; run `sh scripts/test.sh`. Refine this brief before starting.

## Goal

Every std feature edits the same four files in `selfhost/src`: `stdlib.nra` (the `STD_FUNCS` table, 589 lines), `stdcalls.nra` (checks, 741), `emitstd.nra` (emitters, 670) and the generated `runtimetext.nra`. `plan.py check` warns that four open nodes edit each of them. Move the code into one file per std module, with no behavior change, so later std nodes add a file and one registration line.

## Context

- `TestSelfhostBuiltins` compares the registry order with Go's builtin dump (prelude, then `moduleList` order, functions by export name). Keep the final `STD_FUNCS` order identical: build it by concatenating per-module arrays in that order in one registration function.
- `checkStdCall` and the emit dispatch switch on the builtin name. Keep one central dispatch that forwards per module, so a new module adds one `case` line.
- `runtimetext.nra` is generated by `TestSelfhostRuntimeText` (`compiler/internal/narra/selfhost_runtime_test.go`) from the Go runtime files. Generate one file per Go runtime source instead (`runtimecore.nra` for `runtime.h`, `runtimeio.nra` for `runtime_io.h`, and so on), with `runtimeFor(path)` left in a small hand-written file. A node that changes one runtime file then regenerates one `.nra` file.

## Acceptance

- [ ] One file per std module, named `std<module>.nra` flat in `selfhost/src` (`stdfs.nra`, `stdint.nra`, `stdinternal.nra`, ...; later briefs use these names), holding that module's `STD_FUNCS` rows, checks and emitters. `stdlib.nra`, `stdcalls.nra` and `emitstd.nra` keep only shared helpers, the registration point and the dispatch.
- [ ] Generated runtime text is one file per Go runtime source; `NARRA_UPDATE=1 go test -run TestSelfhostRuntimeText` rewrites them and the test fails when one is stale.
- [ ] No behavior change: stage 1 and stage 2 C for every `testdata/*.nra` is byte-identical to main's; no test expectations change.
- [ ] `selfhost/CLAUDE.md` gets one line on where a new std module's rows, checks and emitters go.
- [ ] Fast check passes, including `TestSelfhostBootstrap`.

## Sizing

M. Mechanical move of about 2,000 lines plus a generator change; uncertainty low, verification automatic (byte-identical C).

## Notes for the worker

- Start from the latest main, after the four nodes above merged. Do nothing else in this change, so the review only checks that code moved.
- Shadowing is an error in Narra and names are module-scoped: moved private helpers used by several modules stay in the shared file and become exported.
